retrofit-graphql API Documentation

Multi-module Kotlin library for injecting .graphql files into Retrofit HTTP requests.

  • annotations — @GraphQuery annotation
  • api — Public API interfaces and models
  • android-assets — Asset-based query discovery
  • runtime — Retrofit Converter.Factory
  • codegen-core — Code generation engine
  • serialization-gson — Gson backend
  • serialization-kotlinx — kotlinx.serialization backend
  • library — Legacy facade (deprecated type aliases)
